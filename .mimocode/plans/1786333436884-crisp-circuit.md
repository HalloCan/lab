# ShakeRandomGenerator 熵采集优化方案

## 当前问题

1. **原始值直接入池** — 包含重力分量和设备姿态偏移，低熵
2. **magnitude 差值判定** — 只看总量变化，丢失各轴独立信息
3. **float 直接存储** — 跨设备浮点表示不一致
4. **每样本都做 SHA-256** — 不必要，SHA 不增加熵，只做压缩
5. **最终输出 SHA-256** — 用户要求改为 SHA-512

## 修改文件

| 文件 | 改动程度 |
|------|----------|
| `app/src/main/java/com/htoc/lab/utils/ShakeRandomGenerator.kt` | 重写核心逻辑 |

## ShakeRandomGenerator 改动细节

### 新增状态变量

```kotlin
private var prevX = 0f
private var prevY = 0f
private var prevZ = 0f
private var hasPrevSample = false
```

删除 `lastMagnitude`。

### onSensorChanged 改为差分 + 阈值过滤

```
每帧传感器回调:
  1. 如果是第一个采样，只记录 prevX/Y/Z，不入池
  2. 计算差分: dx = x - prevX, dy = y - prevY, dz = z - prevZ
  3. 更新 prevX/Y/Z = x/y/z
  4. 计算变化量: delta = abs(dx) + abs(dy) + abs(dz)
  5. 如果 delta < shakeThreshold，丢弃（静止/微抖）
  6. 否则: 量化为 milli-g 整数，写入熵池
```

### 量化编码（跨设备一致）

```
quantized = (value * 1000).roundToInt()  // 毫重力单位，消除浮点差异
每个轴 4 字节 Int (大端序)
3 轴 × 4 字节 = 每次采样 12 字节
```

### 熵池写入（移除单样本 SHA）

不再对每个样本做 SHA-256，直接将量化后的 12 字节差分数据追加到 `collectedBytes`。

> SHA-256 是确定性函数，对已有熵做哈希不会增加熵，只是压缩。
> 在这里直接存储原始差分字节，让最终哈希一次性处理全部熵池。

### 最终哈希改为 SHA-512

```
SHA-512(entropyPool + timestamp_salt)
取前 32 字节 (256-bit) 转 hex 输出
```

### shakeThreshold 语义变化

| 旧 | 新 |
|---|---|
| magnitude 差值阈值 (m/s²) | abs(dx)+abs(dy)+abs(dz) 阈值 (m/s²) |

默认值从 10 改为 3（差分值天然比 magnitude 小，需要更低阈值）。

滑块范围调整：布局中 `valueFrom` 从 1 改为 1，`stepSize` 从 1 改为 1（不变），但标签文案更新。

### onSensorData 回调签名变化

```kotlin
// 旧
onSensorData: ((x: Float, y: Float, z: Float) -> Unit)?

// 新
onSensorData: ((dx: Int, dy: Int, dz: Int, rawX: Float, rawY: Float, rawZ: Float) -> Unit)?
```

传出差分量化值 + 原始值，Fragment 根据 checkbox 决定显示哪个。

## WiggleFragment 适配

- `onSensorData` 回调改为接收新签名
- checkbox 勾选时显示差分量化 hex，未勾选时显示掩码
- 阈值滑块默认值改为 3
