# 自相关检测方案

## 问题

RLE 只能检测完全相同的连续字节（`01 01 01`），无法检测周期性模式如：
```
01 02 03 04
01 02 03 04
01 02 03 04
```

用户摇晃手机时，周期性运动产生的差分值在绝对数值上不会完全相同，但存在相似的趋势循环。

## 方案：自相关检测 (Autocorrelation)

### 原理

对环形缓冲区中的信号 x[0..N-1]，计算每个候选周期 lag 的自相关系数：

```
r(k) = Σ(x[i] - mean)(x[i+k] - mean) / sqrt(Σ(x[i]-mean)² × Σ(x[i+k]-mean)²)
```

- `r(k) ≈ 1.0` → 信号在周期 k 处高度重复
- `r(k) ≈ 0.0` → 无周期性
- 扫描 k ∈ [2, N/2]，取最大值 `maxR = max(r(k))`

### 为什么能检测"相似趋势"

自相关比较的是信号的**变化趋势**而非绝对值。即使：
```
序列 A: 01 02 03 04 01 02 03 04
序列 B: 02 04 06 08 02 04 06 08  （值不同，但趋势相同）
```
两者在 lag=4 处都会得到高 r(k)，因为"上升→上升→上升→下降"的模式一致。

### 实现

在 EntropyEstimator 中新增：

```kotlin
/**
 * 自相关系数最大值，范围 [0.0, 1.0]。
 * 扫描 lag ∈ [2, ringCount/4]，取最大归一化自相关。
 * 高值表示存在周期性重复倾向。
 */
val maxAutocorrelation: Double
```

计算步骤：
1. 从环形缓冲区提取有序数组 `x[0..N-1]`
2. 计算均值 `mean`
3. 对每个 lag ∈ [2, N/4]：
   - 计算分子 `Σ(x[i]-mean)(x[i+lag]-mean)`，i ∈ [0, N-lag-1]
   - 计算分母 `sqrt(Σ(x[i]-mean)² × Σ(x[i+lag]-mean)²)`
   - `r(lag) = 分子 / 分母`
4. 返回 `max(r(lag))`

### predictabilityScore 整合

```kotlin
val predictabilityScore: Double
    get() {
        if (ringCount < 64) return 0.5

        val rleScore = (2.2 - rleCompressionRatio()) / 1.2  // RLE 部分
        val autoScore = 1.0 - maxAutocorrelation              // 自相关部分（相关越高→评分越低）

        // 取两者中更严格的（更低的）
        return min(rleScore, autoScore).coerceIn(0.0, 1.0)
    }
```

### 性能

- 环形缓冲区 512 字节，扫描 lag ∈ [2, 128]
- 每个 lag 需要 O(N) 次运算
- 总计 O(N²/4) ≈ 65536 次运算，每帧调用一次，可接受
- 如果性能不足，可以降采样（每隔 N 字节触发一次自相关计算）
