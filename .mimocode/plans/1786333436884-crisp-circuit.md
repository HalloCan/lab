# Emoji 映射方案

## 设计

将 256-bit 随机值（64 位 hex）的每个字节映射为一个 emoji，显示 32 个 emoji 作为随机值的可视化表示。

### 映射规则

- 随机输出 32 字节 → 32 个 emoji
- 每个字节 (0-255) 对应 `byte % 64` → 从 64 个精选 emoji 中选取
- 64 个 emoji 覆盖不同类别（动物、食物、自然、物体等），视觉区分度高

```
🍞🧀🍖🍗🌭🍔🍟🍕🌮🌯🥙🥚🍳🥘🍲🥗🍿🍩🍪🎂🍰🍫🍬🍭🍮🍯☕🍵🥤🍶🍺🍻🥂
```

### UI

在现有 `edit_result` (hex) 下方新增一个 `emoji_result` TextView：
- 字体较大（textAppearanceHeadlineMedium），emoji 天然好看
- 点击同样复制到剪贴板
- 布局与 hex 结果并列显示
