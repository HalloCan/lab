# Hex-Emoji 互转页面

## 功能

两个输入框，双向实时转换：
- 输入 hex → 实时显示对应 emoji
- 输入 emoji（从 emoji 键盘选择）→ 实时显示对应 hex

## EmojiMapper 扩展

新增 `mapToHex(emoji: String): String` 反向映射：
- 每个 emoji → 在 table 中的索引 (0-63)
- 索引转为 2 位 hex (00-3F)
- 注意：正向映射 byte%64 是多对一，反向只能恢复索引而非原始字节
