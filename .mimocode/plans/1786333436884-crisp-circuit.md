# NFC 数据交换 — 改用 NDEF Push 方案

## 问题

HCE (Host Card Emulation) 激活时，AOSP 系统 NFC 服务会在 `HostEmulationManager` 中硬编码显示"正在刷卡"通知，应用层无法抑制。Foreground Dispatch 工作在 Intent 层，无法拦截 APDU/RF 层的系统通知。

## 方案：NDEF Push + Reader Mode（无 HCE）

**核心思路**：用 `setNdefPushMessage()` 替代 HCE，接收端推送 NDEF 消息，发送端用 Reader Mode 读取。

### 数据流（一次碰触完成双向交换）

```
发送端 (Reader Mode)                 接收端 (NDEF Push)
    |                                    |
    | 用户输入消息，点"发送"              | 用户输入回复，点"接收"
    | -> enableReaderMode()              | -> setNdefPushMessage(回复数据)
    |                                    |
    | ========== 碰一碰 ==========       |
    |                                    |
    | Tag discovered (NDEF)              | NDEF 自动推送给发送端
    | -> 读取接收端的 NDEF 消息          |    (系统自动处理)
    | -> 提取接收端的回复文本             |
    |                                    |
    | -> 写入发送端的消息到 NDEF Tag      | 收到写入的 NDEF 消息
    |    (Ndef.writeNdefMessage)          | -> ACTION_NDEF_DISCOVERED
    |                                    | -> 显示发送端的消息
    | -> 显示接收端的回复                 |
```

**无 HCE → 无"正在刷卡"通知**

### 工作原理

1. **接收端**调用 `NfcAdapter.setNdefPushMessage()` 设置要推送的 NDEF 消息（包含回复文本）
2. **发送端**用 `enableReaderMode()` 进入读卡器模式
3. 两台手机碰触时，NFC 系统自动将接收端的 NDEF 消息推送给发送端（类似读取 NFC 标签）
4. 发送端通过 `Ndef.writeNdefMessage()` 将自己的消息写入接收端的 NDEF 标签
5. 接收端通过 `ACTION_NDEF_DISCOVERED` intent 收到写入的数据

## NfcFragment.kt 重写设计

### 状态管理
```
isSending = false, isReceiving = false  → 初始状态
isSending = true                        → 发送模式（Reader Mode）
isSending = false, isReceiving = true   → 接收模式（NDEF Push）
```

### 发送端流程
```
onSendClicked()
  → isSending = true
  → enableReaderMode()  // 进入读卡器模式

onResume()
  → if (isSending) enableReaderMode()  // 恢复读卡器模式

handleTagDiscovered(tag)
  → IsoDep.connect()
  → 读取 Ndef: tag.ndef  // 获取接收端推送的 NDEF 消息
  → 提取接收端回复文本
  → 写入发送端消息: ndef.writeNdefMessage(responseMsg)
  → 关闭连接
  → 显示收到的接收端回复
```

### 接收端流程
```
onReceiveClicked()
  → isReceiving = true
  → nfcAdapter.setNdefPushMessage(ndefMsg, activity)
  → nfcAdapter.setOnNdefPushCreateCallback(callback, activity)
  // NDEF 消息包含接收端的回复文本

onResume()
  → 注册 NDEF_DISCOVERED IntentFilter
  → if (isReceiving) 重新设置 NDEF Push

ACTION_NDEF_DISCOVERED intent
  → 解析 NdefMessage
  → 提取发送端消息文本
  → 显示收到的数据
```

### NDEF 消息结构
```
NdefMessage:
  NdefRecord:
    tnf: TNF_MIME_MEDIA (0x02)
    type: "application/com.htoc.lab.nfc"
    payload: UTF-8 编码的消息文本
```

### 关键 API 调用

**接收端（设置 NDEF Push）：**
```kotlin
val record = NdefRecord.createMime(
    "application/com.htoc.lab.nfc",
    message.toByteArray(Charsets.UTF_8)
)
val ndefMsg = NdefMessage(arrayOf(record))
nfcAdapter.setNdefPushMessage(ndefMsg, activity)
```

**发送端（读取 + 写入）：**
```kotlin
val ndef = Ndef.get(tag)
ndef.connect()
// 读取接收端数据
val receivedMsg = ndef.ndefMessage  // 接收端推送的 NDEF
val text = String(receivedMsg.records[0].payload, Charsets.UTF_8)
// 写入发送端数据
val writeRecord = NdefRecord.createMime("application/com.htoc.lab.nfc", myMsg.toByteArray())
ndef.writeNdefMessage(NdefMessage(arrayOf(writeRecord)))
ndef.close()
```
