# 主页设计方案 - Idea Forge

## 项目现状

- **技术栈**: Kotlin + XML 布局 + Material Design 3 (Theme.Material3.DayNight.NoActionBar)
- **包名**: `com.htoc.lab` | **应用名**: "Idea Forge"
- **当前状态**: 仅有一个空的 MainActivity (Hello World)
- **已有依赖**: Material 1.14.0, ConstraintLayout, AppCompat, Activity KTX

## 设计思路

由于这是一个测试项目，未来会不断增加新页面，采用 **单 Activity + Navigation Component + Fragment** 的架构，便于页面管理和扩展。

### 页面结构

```
MainActivity (承载 NavHostFragment)
├── HomeFragment       — 主页，展示所有功能入口卡片
├── AboutFragment      — 说明页，介绍项目用途
└── DemoFragment       — 功能示范模板页，后续新增页面可参考此模板
```

### 主页设计 (Material Design 3)

- **TopAppBar**: 显示应用名 "Idea Forge"
- **内容区**: 使用 RecyclerView + GridLayout，每个功能以 MaterialCardView 展示
- **卡片内容**: 图标 + 标题 + 简短描述
- **点击卡片**: 导航到对应页面

### 说明页设计

- **TopAppBar**: 带返回箭头
- **内容**: 项目简介、用途说明、技术栈信息
- **Material3 Card**: 分段展示信息

### 功能示范模板页

- **TopAppBar**: 带返回箭头，显示页面标题
- **内容区**: 标准的演示区域，可替换为任意测试内容
- **底部操作区**: FloatingActionButton 或 Button 用于触发测试操作

## 实现步骤

### Step 1: 添加 Navigation 依赖

修改 `gradle/libs.versions.toml`:
- 添加 navigation 版本: `navigation = "2.9.0"`
- 添加库: `androidx-navigation-fragment-ktx`, `androidx-navigation-ui-ktx`

修改 `app/build.gradle.kts`:
- 添加 navigation 依赖引用

### Step 2: 创建导航图

新建 `app/src/main/res/navigation/nav_graph.xml`:
- 定义 `homeFragment` 为 startDestination
- 定义 `aboutFragment` 和 `demoFragment`
- 设置 action 和动画过渡

### Step 3: 修改 MainActivity

修改 `app/src/main/java/com/htoc/lab/MainActivity.kt`:
- 设置 NavHostFragment
- 配置 Toolbar 与 NavigationUI 联动
- 处理 Edge-to-Edge

修改 `app/src/main/res/layout/activity_main.xml`:
- 添加 MaterialToolbar
- 添加 NavHostFragment 容器

### Step 4: 创建 HomeFragment

新建 `app/src/main/java/com/htoc/lab/HomeFragment.kt`:
- 初始化 RecyclerView
- 设置卡片数据和点击事件
- 点击卡片导航到对应页面

新建 `app/src/main/res/layout/fragment_home.xml`:
- CoordinatorLayout 包含 RecyclerView
- 使用 GridLayoutManager (2列)

新建 `app/src/main/res/layout/item_feature_card.xml`:
- MaterialCardView 包含图标、标题、描述

### Step 5: 创建 AboutFragment

新建 `app/src/main/java/com/htoc/lab/AboutFragment.kt`:
- 简单的静态内容展示

新建 `app/src/main/res/layout/fragment_about.xml`:
- ScrollView + MaterialCardView 展示项目信息

### Step 6: 创建 DemoFragment (模板)

新建 `app/src/main/java/com/htoc/lab/DemoFragment.kt`:
- 模板 Fragment，接收页面标题参数
- 包含基础的交互示例

新建 `app/src/main/res/layout/fragment_demo.xml`:
- 标准模板布局

### Step 7: 更新资源文件

更新 `app/src/main/res/values/strings.xml`:
- 添加所有页面需要的字符串资源

更新 `app/src/main/res/values/colors.xml`:
- 添加 Material3 主题色

## 验证方式

1. 构建项目: `./gradlew assembleDebug`
2. 安装到设备/模拟器，验证:
   - 主页正确显示功能卡片网格
   - 点击"关于"卡片可导航到说明页
   - 点击"功能示范"卡片可导航到模板页
   - 返回按钮正常工作
   - Material3 主题正确应用
   - Edge-to-Edge 显示正常
